# Escala de Mídia IBNE — PWA de Testes

Cópia isolada do PWA para validar instalação e acesso ao aplicativo de testes.

- Aplicativo de testes: https://ibne-escala-midia-teste.streamlit.app/
- PWA oficial separado: https://wllmslv10.github.io/ibne-pwa/
- Identidade de instalação e cache próprios.
- O service worker armazena somente arquivos estáticos; não armazena credenciais, dados pessoais, escalas ou chaves Firebase.

O GitHub Actions publica a branch `main`. Configure GitHub Pages para usar GitHub Actions, se necessário. Não copie segredos para este repositório.
